# PART 1: BUSINESS MODEL OVERVIEW

## Revenue Strategy

Alongside uses a **freemium model** with three tiers:

| Tier | Price | Target User |
|------|-------|-------------|
| **Free** | £0 | Try before committing, basic needs |
| **Personal** | £9.99/month or £89/year | Individuals wanting full features |
| **Family** | £14.99/month or £129/year | Households (up to 5 profiles) |

### Why Freemium?

1. **Low barrier to entry** - Our target users have been burned by fitness apps before
2. **Build trust first** - They need to experience the compassion before paying
3. **Word of mouth** - Free users recommend to friends
4. **Ethical alignment** - Basic wellbeing support shouldn't be paywalled

---

## Core Principle: Never Paywall Safety

**These features are ALWAYS free:**

- ✅ Burnout detection and recovery mode
- ✅ Condition management and pain tracking
- ✅ Basic check-in (energy, mood)
- ✅ Safety messaging and warnings
- ✅ Crisis resources (if needed)
- ✅ Basic progress view

**Rationale:** Our ethical commitments require that safety features are never monetised. A user in burnout or pain should never see "upgrade to access recovery mode."

# PART 4: FEATURE GATING LOGIC

## How Gating Works

### Soft Gates (Encouragement)

Features that show but prompt upgrade:

```javascript
function checkFeatureAccess(feature, userTier) {
  const softGates = [
    'coach-personality-change',
    'detailed-analytics',
    'custom-programme',
    'photo-storage'
  ];
  
  if (softGates.includes(feature) && userTier === 'free') {
    return {
      access: false,
      type: 'soft',
      message: 'This feature is available with Personal. Would you like to learn more?',
      showPreview: true
    };
  }
}
```

**Soft gate behaviour:**
- User sees the feature exists
- Can preview what it would look like
- Gentle prompt to upgrade
- Easy to dismiss

### Hard Gates (Blocked)

Features that require upgrade to access:

```javascript
function checkFeatureAccess(feature, userTier) {
  const hardGates = [
    'unlimited-programmes',
    'full-exercise-library',
    'data-export',
    'unlimited-history'
  ];
  
  if (hardGates.includes(feature) && userTier === 'free') {
    return {
      access: false,
      type: 'hard',
      message: 'Upgrade to Personal to unlock this feature.',
      showPreview: false
    };
  }
}
```

### Never Gated

Features that are always free:

```javascript
const neverGated = [
  'burnout-detection',
  'recovery-mode',
  'condition-pain-tracking',
  'basic-checkin',
  'safety-messaging',
  'basic-progress'
];

// These features ALWAYS return access: true
```

## Upgrade Prompts

### When to Show Upgrade Prompts

| Trigger | Prompt Type | Timing |
|---------|-------------|--------|
| Hit session limit | Soft | After 4th session that week |
| Try to access locked programme | Soft | On programme selection |
| Try to change coach personality | Soft | In settings |
| Complete free programme | Soft | On completion |
| 14 days of consistent use | Soft | After check-in |
| Try to access analytics | Soft | On progress view |

### When NOT to Show Upgrade Prompts

| Scenario | Why |
|----------|-----|
| During session | Disruptive |
| Low mood check-in | Insensitive |
| Burnout detected | Unethical |
| First 7 days | Too soon |
| Just dismissed prompt | Annoying |

### Prompt Frequency Limits

```javascript
const promptRules = {
```

# PART 5: SUBSCRIPTION MANAGEMENT

## Subscription States

```javascript
const subscriptionStates = {
  NONE: 'none',           // Free tier
  TRIAL: 'trial',         // 7-day trial
  ACTIVE: 'active',       // Paid and current
  PAST_DUE: 'past_due',   // Payment failed, grace period
  CANCELLED: 'cancelled', // Cancelled but access until period end
  EXPIRED: 'expired'      // Access reverted to free
};
```

## State Transitions

```
NONE → TRIAL (start trial)
TRIAL → ACTIVE (subscribe)
TRIAL → NONE (trial ends, no subscribe)
ACTIVE → CANCELLED (user cancels)
ACTIVE → PAST_DUE (payment fails)
CANCELLED → EXPIRED (period ends)
PAST_DUE → ACTIVE (payment succeeds)
PAST_DUE → EXPIRED (grace period ends)
EXPIRED → ACTIVE (resubscribe)
```

## Grace Periods

| State | Grace Period | Behaviour |
|-------|--------------|-----------|
| Past Due | 7 days | Full access, payment retry |
| Cancelled | Until period end | Full access |
| Expired | 0 days | Immediate downgrade to Free |

## Downgrade Handling

When user downgrades from Personal to Free:

### Data Preservation

| Data | What Happens |
|------|--------------|
| All history | Preserved (but only 30 days viewable) |
| Conditions | First 2 preserved, others hidden (not deleted) |
| Programmes | Reverts to starter library |
| Goals | First goal preserved, others hidden |
| Progress photos | Preserved but not viewable |
| Custom programmes | Hidden but not deleted |

# PART 10: LEGAL REQUIREMENTS

## Terms of Service

Must cover:
- Subscription terms
- Auto-renewal disclosure
- Cancellation policy
- Refund policy
- Data usage
- Liability limitations

## Refund Policy

| Scenario | Refund |
|----------|--------|
| Within 14 days, not used | Full refund |
| Within 14 days, used | Pro-rata refund |
| After 14 days | No refund (but cancel anytime) |
| Technical issues preventing use | Full refund |
| Billing error | Full correction |

## Auto-Renewal Disclosure

Required messaging before first charge:
> "Your subscription will automatically renew at £9.99/month. You can cancel anytime in Settings."

Required messaging before annual renewal:
> "Your annual subscription will renew on [date] at £89. Cancel before this date to avoid being charged."
